# Shynayber Passos | Fisioterapia

Landing page em HTML, CSS e JavaScript puro.

## Testar localmente
`python3 -m http.server` e abrir http://localhost:8000

## Antes de publicar
- Confirmar o número do WhatsApp em `js/script.js` (`WA_NUMBER`).
- Trocar `SEU-DOMINIO.com.br` no `index.html`.
- Substituir os espaços de foto (hero e Sobre) por fotos reais.
- Preencher campos marcados como `PENDENTE` (CREFITO, horários, mapa, formação).
